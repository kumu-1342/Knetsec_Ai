**结论**：LIVE 用例 13/13 通过，最优一轮 12/13 源真实抓取成功；在随后的演示采集中，**26 个数据源累计入库 543 条情报**（含 GitHub GHSA 143 条、GitHub Releases 18 条、NVD 84 条、arXiv 36 条、厂商与媒体 200+ 条），远超「≥5 个源成功」验收线。失败项分为两类并在代码/文档中处理：

- **配额类**（GitHub core 60/h、NVD 限流）：配置 `GITHUB_TOKEN` / `NVD_API_KEY` 即恢复；

> 说明：验收当天因多轮实测耗尽 GitHub 未认证配额（core 0/60），GHSA 在演示采集轮中返回 403；该现象已被 UI 与运行日志如实记录，属于预期外部约束，配置 Token 后消失（详见 06 部署手册 §Token 配置）。

## 8. 缺陷与修复记录

| # | 现象 | 根因 | 修复 | 验证 |
|---|---|---|---|---|
| D1 | CNVD 采集失败 | 本机 schannel 吊销检查离线（CRYPT_E_REVOCATION_OFFLINE），非站点封禁 | 源保留默认停用 + `KNETSEC_HTTP_PROXY` 代理开关 + 文档说明 | 失败仅记录，不影响其他源 |
| D2 | CISA KEV 偶尔失败 | Akamai 边缘节点 TCP 连接超时 | 增加一次 2s 重试；LIVE 测试归类为网络敏感 | 重试后 33 条成功 |
| D3 | GHSA 请求返回 422 | `published` 只接受 date-only | 改为 `YYYY-MM-DD` | 60 条成功 |
| D4 | ghsa-ai 返回 0 条 | `ecosystem` 与 `published` 不能同时传 | 按 ecosystem 分请求 + 本地时间窗过滤 | 94 条成功 |
| D5 | AI 安全误分类（Barracuda→cuda、Arraytics→ray） | 关键词子串匹配 | 语义边界匹配（前后非 ASCII 字母数字），中文保持 includes | 回归单测 5 条，分类恢复 |
| D6 | 报告「AI 安全」章混入 SQL 注入 | taxonomy 的 `rag` 命中 `storage` | 同上边界匹配 | 清库重采后验证 |
| D7 | 所有测试无法启动 | vitest.config.ts 块注释被 `tests/**/*.test.ts` 的 `*/` 提前闭合 | 重写配置（改为行注释） | 134 用例通过 |
| D8 | 前端 vue-tsc 失败 TS5101 | 根 node_modules 解析到 TypeScript 6，`baseUrl` 已废弃 | web tsconfig 删 baseUrl、paths 改相对路径 | typecheck 通过 |
| D9 | scrypt 类型报错 | `util.promisify` 丢失带 options 的重载 | 手写 Promise 包装 | tsc 通过 |
| D10 | `@fastify/jwt` 类型增强报 TS2664 | 增强了错误的模块（'@fastify/jwt' 而非 'fastify'） | 改 `declare module 'fastify'` + import | tsc 通过 |
| D11 | sources 路由 `ReturnType<typeof HttpClient>` 报 TS2344 | class 不是函数 | 直接用 `HttpClient` 类型 | tsc 通过 |
| D12 | stats 聚合字段名仍是 snake_case | SQL 别名未映射 | map 为 camelCase | typecheck 通过 |
| D13 | 客户端 401 误报「登录过期」 | 登录接口 401 被统一拦截 | 登录请求单独分支处理 | UI 验收通过 |
| D14 | 渲染器表格竖线被误拆列 | 行内转义 `\|` 与分列逻辑冲突 | 占位符方案 | 单测通过 |
| D15 | 测试并发打开 SQLite 句柄竞争 | 多测试文件并行 | `fileParallelism: false` | 测试稳定 |

## 11. 遗留问题与建议

| 级别 | 问题 | 建议 |
|---|---|---|
| P2 | GitHub 未认证配额在密集实测时耗尽（60/h） | 生产配置 `GITHUB_TOKEN`（5000/h） |

| P3 | `watched` 筛选仍是 SQL LIKE 子串匹配 | v1.1 改应用层边界匹配或 REGEXP |
| P3 | SystemInfo/SchedulerStatus 未收敛进 shared | v1.1 上移，消除前端本地类型 |
| P3 | Cisco RSS 被反爬、Unit42 限速 | 换官方公告 API 或调大超时/重试 |

**结论：v1.0.0 通过验收，可交付使用。** 上述遗留项均为增强项，不影响核心链路（采集→去重→报告→面板）。
