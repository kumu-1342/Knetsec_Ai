## 文档维护约定

1. **单一事实来源**：技术选型、数据模型、API 契约以 00 与 `packages/shared` 为准；文档与代码冲突时先修代码或先修契约，再统一文档。
2. **编号即主键**：需求 `FR-xx`、非功能 `NFR-xx`、风险 `R-xx` 不复用；02 的追踪矩阵必须能定位到 03 章节与 09 端点。
3. **命令可复制**：所有命令使用 Windows PowerShell 写法，路径以 `D:\Knetsec_Ai` 为根；不要出现「某目录」这类占位。
4. **变更留痕**：每篇文档末尾有「变更记录」表；结构性变更（新增端点、新增表、新增环境变量）必须在同一提交内更新相关文档。
5. **格式**：Markdown + GitHub 风格表格 + 围栏代码块；提交前执行 `npx prettier --write "docs/**/*.md"`。

## 快速开始

```powershell
cd D:\Knetsec_Ai
npm install            # 首次安装（postinstall 自动构建 shared）
npm run dev            # 开发：server:8787 + web:5173
npm run build          # 生产构建
npm start              # 生产启动（server 托管面板）
```

详细步骤见 [06-部署与运维手册](./06-部署与运维手册.md)。
